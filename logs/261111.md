# 2026-11-11 작업 기록

## 1. Bodyweight의 근육 XP 제외

[이전 논의](261028.md)의 미결정 사항을 마무리했다. 근육 XP는 Strength Training의 Machine과 Free Weight에만 지급하고 Bodyweight에는 지급하지 않는다. Bodyweight에 별도 Load를 기록하더라도 mode 기준으로 제외한다. 기존 유효 수행 기준인 실제 reps 1회 이상의 세트와 선택적 Load는 Machine과 Free Weight에 그대로 적용한다.

상세 문서: [Product Concept](../docs/product-concept.md), [Domain Glossary](../docs/domain-glossary.md), [Product Roadmap](../docs/roadmap.md)

## 2. 웨이트 외 운동의 직접 XP 제외

Bodyweight, Cardio/Endurance, Sport, Mobility/Recovery, Other 운동 기록에는 당분간 근육 XP뿐 아니라 다른 직접 운동 XP도 주지 않는다. 별도 활동 보상 규칙을 만들지 않아 초기 성장 규칙을 단순하게 유지한다. 다른 기록에서 별도로 얻는 XP를 제한하는 결정은 아니다.

상세 문서: [Product Concept](../docs/product-concept.md), [Domain Glossary](../docs/domain-glossary.md), [Product Roadmap](../docs/roadmap.md)

## 3. Custom 운동의 최근 대상 근육 재사용

같은 picker에서 이름이 정확히 일치하는 custom 운동을 다시 사용하면 가장 최근에 확정·저장한 대상 근육을 기본값으로 채운다. 기존 string 동일성 규칙대로 정규화하지 않으며, 사용자는 기본값을 바꿀 수 있다. 저장된 일치 항목이 없으면 빈 상태에서 시작한다. 반복 사용 시 입력을 줄이되 현재 수행의 선택권은 유지하기 위한 결정이다.

상세 문서: [Product Concept](../docs/product-concept.md), [Domain Glossary](../docs/domain-glossary.md), [Product Roadmap](../docs/roadmap.md)

## 4. 기본 운동의 최근 대상 근육 재사용

기본 운동도 이전에 확정·저장한 기록이 있으면 가장 최근 대상 근육 선택을 다음 입력의 기본값으로 채운다. 빈 선택도 유지하며 사용자는 다시 수정할 수 있다. 저장 기록이 없는 첫 사용에는 주 대상 근육만 포함한 catalog 기본값을 쓴다. 이는 재사용 입력을 줄이기 위한 개인별 prefill이며 catalog 기본 연결을 바꾸지는 않는다.

상세 문서: [Product Concept](../docs/product-concept.md), [Domain Glossary](../docs/domain-glossary.md), [Product Roadmap](../docs/roadmap.md)

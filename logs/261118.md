# 2026-11-18 작업 기록

## 1. 독립 바디스캔 페이지 제거

홈에 바디스캔과 근육 상태가 이미 통합되어 별도 `/bodyscan` 경로를 제거했다. 홈의 공통 뷰어와 경험치 기능은 유지하며 제거된 경로는 기존 라우터의 없는 페이지 처리에 맡긴다.

## 2. 바디스캔 선택을 XP 그룹과 통합

바디스캔의 세부 선택 영역을 경험치에서 사용하는 11개 근육 그룹 키로 통일했다. XP 이벤트와 운동 대상 근육은 이미 `Back`/`Core` 단위로 기록되고 있어, 저장 데이터나 XP 합산 로직은 바꿀 필요가 없었다. 등·코어의 여러 3D 영역을 각각 유지하는 대신 같은 그룹의 하나의 선택 영역으로 합쳐 상태 카드, 키보드 탐색, 3D 강조가 같은 그룹을 선택하게 했다.

`pnpm test`, `pnpm exec tsc --noEmit`, `pnpm build` 통과.

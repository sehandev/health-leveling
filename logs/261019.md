# 2026-10-19 작업 기록

## 1. 제품 및 도메인 방향 정리

건강 기록, AI/계산 기반 파생 데이터, 화면 표시용 `Presentation Model`을 별도 개념으로 정리했다. 한국어 UI와 영어 canonical domain terms를 병행하고, 장소는 `Place`로 통일해 집·식당·체육관을 포괄하며, InBody 결과는 단일 값이 아니라 개별 `Body Metrics`로 기록하기로 했다. XP는 감소하지 않고 레벨당 필요 XP는 고정한다. 세부 XP 계산과 일부 측정 필드 명칭은 미결정이다.

상세 문서: [Product Concept](../docs/product-concept.md), [Domain Glossary](../docs/domain-glossary.md)

## 2. Cloudflare와 로컬 Pi 연결 방향 결정

Wrangler가 아니라 설치된 `cf` CLI를 Cloudflare 작업의 기본 도구로 사용한다. 현재 버전은 `v1.0.0-beta.18`이므로 버전을 고정하고 업그레이드 시 명령 호환성을 확인한다. 개발 Mac의 Pi CLI RPC는 네트워크 서버가 아니므로 로컬 HTTP bridge가 필요하다. Worker에서 Cloudflare Tunnel과 Access를 거쳐 bridge에 연결하며, Mesh는 Worker에서 Mac으로 직접 연결하는 경로로 사용하지 않는다.

상세 문서: [Cloudflare CLI and Local Pi Bridge](../docs/cloudflare-cli.md)

## 3. 완성까지의 단계 분해

완료까지의 작업을 Product Definition, Platform Foundation, Identity/Data Foundation, Core Logging, XP/Leveling, Dashboard/Progress, AI Insights, Release Readiness로 나눠 [Product Roadmap](../docs/roadmap.md)에 기록했다. Mac의 Pi와 Tunnel 연결은 구현 리스크가 있으므로 초기에 짧게 검증하고, 앱의 기본 기록 흐름은 AI 없이도 동작하도록 순서를 잡았다. 수동 기록과 성장 루프를 우선 출시하는 MVP cut line은 제안일 뿐 아직 확정하지 않았다.
